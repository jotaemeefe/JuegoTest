    Change 1 — Rewrite onDisconnect() (UI-06, per D-16):
    Replace the entire onDisconnect() function body (lines 1006–1011) with:
      function onDisconnect() {
        stopLoop();
        Net.destroy();
        const modal = document.getElementById('disconnect-modal');
        if (modal) {
          modal.hidden = false;
          setTimeout(() => {
            modal.hidden = true;
            goTo('lobby');
          }, 3000);
        } else {
          goTo('lobby');
        }
      }
    Key changes: alert() removed, Net.destroy() moved before modal show (was after goTo in original),
    goTo('lobby') now happens inside setTimeout after 3000ms instead of immediately.
    The else branch (no modal element) is a safety fallback — should not occur in normal use.

    Change 2 — Add copy button click handler (UI-05, per D-15):
    After the existing UI event listeners (after btn-cancel-join handler at ~line 1139),
    add the copy button handler:
      document.getElementById('btn-copy-code').addEventListener('click', () => {
        const code = document.getElementById('room-code-display').textContent.trim();
        const toast = document.getElementById('copy-toast');
        if (!toast) return;
        const showToast = (msg) => {
          toast.textContent = msg;
          toast.classList.add('visible');
          setTimeout(() => toast.classList.remove('visible'), 1500);
        };
        if (navigator.clipboard && navigator.clipboard.writeText) {
          navigator.clipboard.writeText(code).then(() => {
            showToast('¡Copiado!');
          }).catch(() => {
            showToast('Copia el código manualmente');
          });
        } else {
          // Fallback for file:// context or older browsers
          showToast('Copia el código manualmente');
        }
      });

    The `navigator.clipboard && navigator.clipboard.writeText` guard handles the case where
    the game is opened via file:// URL where clipboard API is unavailable (per RESEARCH.md
    clipboard compatibility note). The .catch() handles permission-denied rejections.

    Do NOT modify any other function. The room-code-display textContent is already set by
    the btn-create handler when Net.create() returns the room code.

|----------|-------------|
| navigator.clipboard.writeText | Reads room-code-display DOM text and writes to clipboard — clipboard content is user's own room code |
| network → onDisconnect() | PeerJS fires onDisconnect when peer closes connection — triggers modal |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | navigator.clipboard.writeText | accept | Content written is the 6-char alphanumeric room code (not PII). Requires user gesture (click). Secure context (HTTPS/localhost) required — enforced by browser |
| T-04-02 | Denial of Service | onDisconnect modal | accept | Modal auto-dismisses after 3s; if dismissed, goTo('lobby') still fires. No way to trap user |
| T-04-03 | Spoofing | Premature disconnect signal | accept | PeerJS fires onDisconnect only on genuine connection close. Cannot be triggered by game data messages |
| T-04-SC | Tampering | npm/pip installs | accept | No package manager installs — pure DOM/CSS/JS edits only |
</threat_model>
