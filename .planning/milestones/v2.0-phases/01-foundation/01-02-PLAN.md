    The IIFE must:
    1. Read window.devicePixelRatio, defaulting to 1 if undefined: const dpr = window.devicePixelRatio || 1;
    2. Set canvas.width = 480 * dpr
    3. Set canvas.height = 640 * dpr
    4. Call ctx.scale(dpr, dpr)
    5. Wrap in an IIFE or named function called exactly once so ctx.scale() is never called twice

    The HTML attribute width="480" height="640" on the canvas element in index.html sets the default buffer size before JS runs. This is fine — the JS override replaces it immediately. Do NOT remove the HTML attributes (they serve as a fallback if JS fails to load).

    Critical: After this init, the canvas buffer is 480*dpr x 640*dpr pixels, but the coordinate system is still 480x640 (because ctx.scale(dpr, dpr) applies the scaling). This means ALL existing draw calls (drawTrack, drawCar, drawCountdown, project(), etc.) continue to work unchanged. Do not modify any drawing functions.

    Do not add a window resize or deviceorientation event listener (per D-08 discretion — static init only).

    Name the IIFE clearly: (function initCanvasDPR() { ... })();
  </action>
