    Define a helper function inside buildRivalGrid() (closure over carouselIdx):
      function updateCarousel() {
        const narrow = window.innerWidth < 500;
        const cards = document.querySelectorAll('.rival-card');
        const indicator = document.getElementById('carousel-indicator');
        if (!narrow) {
          // Desktop: remove carousel-active class (all cards show via CSS grid)
          cards.forEach(c => c.classList.remove('carousel-active'));
          if (indicator) indicator.textContent = '';
          return;
        }
        // Mobile: show only carouselIdx card
        cards.forEach((c, i) => c.classList.toggle('carousel-active', i === carouselIdx));
        if (indicator) indicator.textContent = `${carouselIdx + 1} / ${cards.length}`;
      }

    Attach event listeners to the prev/next buttons (these exist in DOM from Task 1):
      const prevBtn = document.getElementById('rival-prev');
      const nextBtn = document.getElementById('rival-next');
      if (prevBtn) {
        prevBtn.onclick = () => {
          const count = document.querySelectorAll('.rival-card').length;
          carouselIdx = (carouselIdx - 1 + count) % count;
          updateCarousel();
        };
      }
      if (nextBtn) {
        nextBtn.onclick = () => {
          const count = document.querySelectorAll('.rival-card').length;
          carouselIdx = (carouselIdx + 1) % count;
          updateCarousel();
        };
      }

    Call updateCarousel() once at the end of buildRivalGrid() to set initial state:
      updateCarousel();

    Note: The onclick assignment (prevBtn.onclick = ...) is intentional — it replaces any previous handler if buildRivalGrid() is called multiple times (e.g., returning from a race to rival select). Using addEventListener would accumulate duplicate handlers across calls.
